One satirical sentence roasting the lawmakers and the file they cannot
convert — the hearings, the consultants, the modernization contract,
and the one thing nobody in the building ever actually did.

The line:

> After six hearings, three consultants, and a $4 million modernization contract, Congress still can't convert the file — but it did convert the failure into a subcommittee, a press release, and a re-election ad.

They couldn't convert the file, so they converted the failure instead:
a subcommittee to study it, a press release to spin it, and an ad to
campaign on it. The punch lands on the last words — the file stays
unconverted, the politicians stay promoted.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, stdlib only) writes the line to `entry.txt` in the
output directory, with no trailing newline so the file is exactly one
line. It validates the gate itself: 1–320 characters, exactly one
sentence, a single line, no double spaces or control characters.
